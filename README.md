# Язык любви — первая версия

Это фронтенд-прототип Telegram Mini App: романтический интерфейс, тест из 20 вопросов, подсчёт пяти направлений и экран результата.

## Что уже работает
- адаптивный интерфейс для телефона;
- 20 вопросов с четырьмя вариантами;
- подсчёт результата по пяти категориям;
- сохранение собственного результата в localStorage этого браузера;
- кнопка поделиться результатом.

## Что пока не подключено
- база данных и синхронизация между телефонами;
- код приглашения партнёра;
- сравнение результатов пары;
- проверка Telegram WebApp initData и серверная часть.

Это будет следующим этапом. Не используйте localStorage как способ обмена результатами между разными устройствами.

## Публикация на GitHub
Загрузите `index.html` и `README.md` в корень репозитория. Затем подключим репозиторий к Vercel.
